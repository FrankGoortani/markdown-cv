CV Chat Interface Test - SSE Endpoint

This page tests the CV chat interface using the new /sse/ endpoint structure.

The chat button should appear in the bottom-right corner. Click it to open the chat and test the various options.

Implementation Details

JSON Files in /sse/ Directory

All responses are now served from JSON files in the /sse/ directory:

  • profile.json - Professional profile
  • skills.json - Skills list
  • interests.json - Professional interests
  • resume.json - Path to resume PDF
  • picture.json - Path to profile picture
  • company-uber.json - Uber experience
  • company-home-depot.json - Home Depot experience
  • search-javascript.json - Search results for "JavaScript"

MCP Server Implementation

The MCP server is implemented as a Cloudflare Worker that connects to these same JSON files:

  • Uses standard MCP protocol for AI assistants
  • Fetches data from https://goortani.com/sse/ endpoints
  • Handles error cases gracefully
  • Provides consistent responses across both web interface and AI assistants

Test Instructions

Try the following features:

  1. Click the chat button to open the interface
  2. Click on buttons like "Profile", "Skills", etc.
  3. Search for "JavaScript" (this is the only pre-computed search term)
  4. Search for company "Uber" or "Home Depot" (these are the only pre-computed companies)
  5. Try other searches to see the graceful error handling
