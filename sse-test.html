CV Chat Interface Test - SSE Endpoint

This page tests the CV chat interface using the new /sse/ endpoint structure.

The chat button should appear in the bottom-right corner. Click it to open the chat and test the various options.

Implementation Details

Direct Cloudflare Worker Integration

All responses are now served directly from a Cloudflare Worker via Server-Sent Events (SSE):

  • https://frank-cv-sse.frank-b2a.workers.dev/sse/profile - Professional profile
  • https://frank-cv-sse.frank-b2a.workers.dev/sse/skills - Skills list
  • https://frank-cv-sse.frank-b2a.workers.dev/sse/interests - Professional interests
  • https://frank-cv-sse.frank-b2a.workers.dev/sse/resume - Path to resume PDF
  • https://frank-cv-sse.frank-b2a.workers.dev/sse/picture - Path to profile picture
  • https://frank-cv-sse.frank-b2a.workers.dev/sse/company?name=uber - Uber experience
  • https://frank-cv-sse.frank-b2a.workers.dev/sse/company?name=home%20depot - Home Depot experience
  • https://frank-cv-sse.frank-b2a.workers.dev/sse/search?q=javascript - Search results for "JavaScript"

MCP Server Implementation

The MCP server is implemented as a Cloudflare Worker that connects to these same JSON files:

  • Uses standard MCP protocol for AI assistants
  • Fetches data from https://frank-cv-sse.frank-b2a.workers.dev/sse endpoints
  • Handles error cases gracefully
  • Provides consistent responses across both web interface and AI assistants
