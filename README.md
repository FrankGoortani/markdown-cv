# goortani.com

Professional profile and full CV of Frank Goortani, served by GitHub Pages from the `gh-pages` branch.

- `/` is the profile; `/cv/` is the complete CV; `/resume/` links the PDF résumés.
- Static HTML plus `profile.css`. Preview with `python3 -m http.server 8080`.

See `AGENTS.md` for how the pages are produced and maintained.
